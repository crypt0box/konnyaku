# キャプチャはコピー操作の擬似送信とクリップボード経由で行う

構造（見出し・リスト・表）と画像を保つには原文をリッチ形式で得る必要がある。アクセシビリティ API の選択テキスト取得（Nani 翻訳と同じ方式）はほぼプレーンテキストしか返さないため採らず、ショートカット押下時にコピー操作を擬似送信してクリップボードの HTML / RTF / テキスト / 画像を読み、元のクリップボード内容を全形式で復元する。コピーで何も取れなかったときは、その時点のクリップボード内容を原文として扱う。

## Consequences

- macOS ではキー送信のためアクセシビリティ権限が必要。
- コピー操作が効かないアプリでは、利用者が手動でコピーしてから同じショートカットを押す運用になる。
