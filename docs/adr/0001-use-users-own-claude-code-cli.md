# 翻訳エンジンは利用者自身がログインした Claude Code CLI を呼び出す

konnyaku は OSS として公開し、翻訳には利用者が自分でインストール・ログインした未改変の Claude Code CLI（`claude -p`）を子プロセスとして呼び出す。アプリは認証情報を一切保持・仲介しない。Anthropic は第三者アプリが claude.ai ログインやサブスク枠を自社製品として提供・仲介することを禁じている（Agent SDK 含む）ため、Agent SDK にサブスク認証を通す案や、アプリ内ログインを持つ案は採らなかった。一般向け製品として配布する段階になったら、API キー方式の翻訳エンジンを追加する。

## Consequences

- 利用者は事前に Claude Code のインストールとログインが必要。
- `--bare` はサブスクの OAuth 資格情報を読まないため使えない（起動短縮は別手段で行う）。
