Getting Started with Rust

Rust is a fast and memory-efficient language. Install it with rustup and read the official book.

Why choose Rust?

  • Performance comparable to C and C++
  • Memory safety without a garbage collector
  • A friendly compiler with helpful error messages
FeatureDescription
OwnershipEach value has a single owner.
BorrowingReferences let you use a value without taking ownership.

    println!("Hello, world!");
